# 课点 · 大学生课堂助手

> 一周一次的大课容易忘作业、听不进去。课点把课表、作业、录音要点、翻译和笔记放在一个地方。

在线体验：<https://hinnn9.github.io/kedian/>

## 功能

| 模块 | 说明 |
|---|---|
| 今天 | 今日课程（自动标"进行中"）+ 待办作业（按截止日排序、逾期预警）+ 会议讲座 |
| 课程表 | 7 天 × 12 节周视图，支持教学周切换、单双周、课程有效期 |
| 录音转要点 | 上传课堂录音 → 语音转写 → AI 提炼：三句话总结 / 老师强调的考点 / 核心知识点 / 章节时间轴 / 布置的作业 |
| 翻译 | 英文段落翻译，支持课程术语表（自定义专业课译法，避免学术词误译） |
| 笔记 | 按科目归类，可从录音要点、翻译结果一键生成 |

## 技术栈

- 前端：Vue 3 + uni-app（一套代码可编译到 H5 / 微信小程序 / App）
- 数据：浏览器 localStorage 本地存储（演示版无后端）
- 语音转写：腾讯云录音文件识别（规划中）
- 摘要：大模型分段提炼（规划中）
- 翻译：腾讯云文本翻译（规划中）

## 本地运行

    npm install
    npm run dev:h5
    npm run build:h5

## 说明

- 语音转写与翻译当前为演示态（预设结果），接入 API 后替换。
- 学期周次按"开学第一周周一"推算，支持单双周与课程起止周。
- 演示数据中人名、学校均为虚构。
